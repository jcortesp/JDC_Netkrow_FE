This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## Avisos y recordatorios por WhatsApp

En Servicio Técnico, guarda los diagnósticos. Cuando todos los equipos activos tienen revisión, mantenimiento, limpieza y calibración en «Ok», aparece «Avisar que está listo».

1. Abre el aviso y envíalo en WhatsApp.
2. Regresa y pulsa «Ya lo envié». Abrir el chat o cancelar no registra un envío.
3. En «Recordatorios WhatsApp» aparecen las remisiones elegibles a partir de 15 días completos desde el último envío confirmado. Cada nuevo recordatorio confirmado inicia otro intervalo de 15 días.

El envío es manual; WhatsApp Web no informa a esta aplicación si el mensaje se envió. Las remisiones entregadas, de garantía o sin equipos activos listos no aparecen en la lista. Los mensajes anteriores a esta función no tienen fecha registrada y requieren un primer aviso confirmado.

Publicar primero el backend con la migración V2 y luego el frontend. Validaciones: `npm test` (Node 22.18+ o 24+) y `npm run build`.
